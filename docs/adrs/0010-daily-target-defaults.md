# Daily target defaults

Status: Accepted

The daily target comes from the profile: basal energy from the Mifflin-St Jeor formula, multiplied by an activity factor to get the total daily energy. The goal changes it: lose weight -15%, keep weight 0%, gain weight +10%. The default macro split is protein 25%, fat 30%, carbohydrate 45% of energy, and the user can change it. The app uses metric units only. Onboarding asks for the profile but the user can skip it; a user without a profile can log meals but sees no target comparison.

Trade-offs: these are general population defaults and are not correct for children, pregnancy, or medical conditions. The app does not give targets for those cases (see [0005](0005-rules-calculate-advice-model-writes-it.md)).
