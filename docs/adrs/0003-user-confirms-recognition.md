# A recognition counts only after the user confirms it

Status: Accepted

Calorie error from a photo is about 20–40%, so a recognition that goes directly into totals makes the daily data wrong. Thus a recognition is shown as a card that the user can change (foods and grams). Only when the user confirms it does it become a meal entry and count in daily totals and health advice.

Trade-offs: logging needs one more tap. Do not add automatic confirmation to save the tap, because totals and advice depend on confirmed data. Keep the user's changes, because they are the test data for model evaluation.
